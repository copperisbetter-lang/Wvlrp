# WVLRP — Flat asset library (curation branch)

**Owner-approved 2026-10-27.** Two permanent folders:

- [approved flats](./approved%20flats/README.md): paid vendor three-shape set, **Flat 01, Flat 02, Flat 03**.
- [unused flats](./unused%20flats/README.md): archived copies of earlier Vulva/Flat 1–2 standalone and integrated prototypes.

**IMPORTANT:** This is the isolated `archive/flat-library-20261027` branch. Nothing is merged into `main`, deployed, removed, or renamed at working model paths. Legacy GLB blobs are duplicated by existing Git blob SHA (byte-identical), not modified. Production is frozen per GitHub Issue #29.

The owner purchased the three new masters for $8. Their license and redistribution terms are unverified, so **the raw paid meshes/textures are not uploaded to this public repository**. Numbered original source files and shared Blender/texture assets are instead held in the owner's downloadable `Flat_Asset_Library_Approved_Flats.zip` archive made in the 2026-10-27 conversation.

Rigging or corrective morphs must be made as working copies; do not alter original masters.
