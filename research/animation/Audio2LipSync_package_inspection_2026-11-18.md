## Verified script behavior
- DAZ script header says: **Audio2LipSync → Daz Studio 1**. Intended workflow: select DAZ figure, open/execute the DSA script in DAZ Script IDE, select the *.lipsync.json generated by Audio2LipSync app.
- Script contains mappings for Genesis 8, Genesis 8.1, and Genesis 9. Each includes 18 canonical channels:
  `jawOpen`, `mouthClose`, `mouthPressLeft`, `mouthPressRight`, `mouthRollLower`, `mouthRollUpper`, `mouthSmileLeft`, `mouthSmileRight`, `mouthStretchLeft`, `mouthStretchRight`, `mouthUpperUpLeft`, `mouthUpperUpRight`, `mouthLowerDownLeft`, `mouthLowerDownRight`, `mouthFunnel`, `mouthPucker`, `tongueOut`, `mouthShrugLower`.
- Source JSON shape read by importer: `clip.frames[]` with per-frame `t` (seconds) and `weights` dictionary keyed by channel IDs.
- Uses `TPS=4800`, turns frame time into DAZ ticks, dynamically resolves matched figure properties (including alias variants), keys property values at each timestamp, adjusts animation/play ranges, and writes `Audio2LipSync_daz_match.txt` match report next to selected JSON.
- Requires actual DAZ face controls on selected figure; script explicitly warns G9/G8.1 need FACS Units and G8 needs Head pose controls (eCTRL).
- This is a **facial animation importer**, not a live in-browser speech-to-lipsync system, and it does not itself export a game-ready GLB or supply the DAZ figure.
