# Wildlife Workshop — The Wild

GitHub Actions can now **download**, **open in Blender**, **inspect geometry/rigging**, and **render four reference views** of each existing wildlife model.

Open Actions → The Wild Wildlife Workshop → Run workflow, then select deer-reference, rabbit-reference, or squirrel-reference. Results are uploaded as a workflow artifact.

This workflow does not change the live game, attach fake rigs to incompatible geometry, or claim the animals have natural motion. Next production work is species-specific quadruped rigs, weight painting, walk/run/idle/eat animations, exports, visual quality checks, and integration after approval.

Source licenses and species IDs must be verified before any production release. A reference deer is not a confirmed West Virginia white-tailed deer; the rabbit isn't confirmed a cottontail, and the squirrel species is undetermined.
