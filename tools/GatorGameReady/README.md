# Gator Game Ready
Native, permission-light Android game preparation app for Samsung Galaxy.
Measures available RAM, Android low-memory pressure, battery saver, thermal state, free storage.
Opens Samsung Device Care for its supported Memory → Clean now button, app settings, battery settings.
Launches a customizable saved Stacey Lake game URL.
No trackers, background services, accessibility hacks, process killers, special permissions, or false RAM-freeing claims.
Android 14+ prevents regular apps from force-closing other apps. Use Samsung Device Care instead.
Built with AGP 8.7.3, Gradle 8.9, JDK17, compileSdk 35.
